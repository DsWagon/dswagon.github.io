# AWTRIX / ESP32

Projet d'afficheur connecté basé sur ESP32 intégrant :

- données Météo-France
- données RATP
- capteurs de température
- intégration Home Assistant
- MQTT
- affichage personnalisé

## Objectif

Créer un afficheur utile au quotidien, capable de centraliser plusieurs sources de données.

## Technologies

ESP32 · MQTT · API · Home Assistant · Python

## Ce que j’ai appris

- récupération et traitement de données via API
- communication entre systèmes
- intégration de capteurs
- affichage temps réel

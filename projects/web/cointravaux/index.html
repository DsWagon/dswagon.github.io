Coin Travaux

Find a contractor before buying !

A Web App that matches you with a contractor before buying a condominium, helping you estimate renovation budgets. It was done during the bootcamp at Le Wagon in june 2023.

This project was done in collaboration with Céline Chader, Amal Rabbani, Stéphanie Bourdillon and Thomas Desmoulins a webiste that helps people estimate renovation budgets before buying a condominium.
